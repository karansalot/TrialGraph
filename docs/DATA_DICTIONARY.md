# TrialGraph data dictionary

_Generated by `trialgraph docs` from the live PostGIS database - do not edit by hand._

Conventions: SRID 4326; `geography` points for distance, `geometry` polygons for containment and display; county key is the 5-digit FIPS/GEOID; tract key is the 11-digit 2020 GEOID; study key is the NCT identifier.
